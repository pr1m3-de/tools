# Dezimalzahlen – Addieren, Subtrahieren, Runden

Name: ___  Datum: ___

Merke: Komma unter Komma, fehlende Stellen mit Nullen auffüllen. Beim Runden zählt nur die erste wegfallende Ziffer: 0–4 ab, 5–9 auf.

Zum Ausprobieren: [Dezimalzahlen](../../../mathe/dezimalzahlen.html) (Zahlenstrahl mit Lupe)

## Aufgabe 1 – Vergleichen und Ordnen

1. Setze <, = oder > ein: $0{,}7$ ___ $0{,}65$
2. $3{,}40$ ___ $3{,}4$
3. Ordne der Größe nach: 2,05; 2,5; 2,055; 2,45

:::lösung
1. > (0,70 > 0,65)
2. =
3. 2,05 < 2,055 < 2,45 < 2,5
:::

## Aufgabe 2 – Addieren

1. $12{,}5 + 3{,}75$
2. $0{,}86 + 4{,}3 + 15$
3. $199{,}99 + 0{,}01$

:::lösung
1. 16,25
2. 0,86 + 4,30 + 15,00 = 20,16
3. 200,00 = 200
:::

## Aufgabe 3 – Subtrahieren

1. $8{,}4 - 2{,}75$
2. $10 - 3{,}62$
3. $5{,}03 - 4{,}9$

:::lösung
1. 8,40 − 2,75 = 5,65
2. 10,00 − 3,62 = 6,38
3. 5,03 − 4,90 = 0,13
:::

## Aufgabe 4 – Runden

Runde auf die angegebene Stelle.

1. 3,1416 auf Hundertstel
2. 2,345 auf Hundertstel
3. 7,96 auf Zehntel
4. 0,4999 auf ganze Zahlen

:::lösung
1. 3,14
2. 2,35
3. 8,0 (Übertrag)
4. 0
:::

## Aufgabe 5 – Materialliste

Für eine Verteilung kaufst du: Klemmen für 12,40 €, Kabel für 37,85 €, Leitungsschutzschalter für 64,50 €.

1. Wie viel kostet alles zusammen?
2. Du zahlst mit 150 €. Wie viel bekommst du zurück?

:::lösung
1. 12,40 + 37,85 + 64,50 = 114,75 €
2. 150,00 − 114,75 = 35,25 €
:::
