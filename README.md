# Formeln & Rechner

Rechner, Formeln und Lernhilfen für Elektro, Mechanik, Sanitär, Heizung, Brandschutz, Arbeitsschutz, Dach, IT und Kalkulation: **https://tools.pr1m3.de**

- Jeder Rechner rechnet in jede Richtung und zeigt den Rechenweg mit den eingesetzten Zahlen.
- Lernbereich mit Übungsaufgaben, Formelkarten und Aufgabenblättern zum Ausdrucken.
- Nur HTML, CSS und JavaScript, keine externen Dateien. Läuft offline und lässt sich als App installieren.

**Mitmachen:** [MITMACHEN.md](MITMACHEN.md) erklärt den Aufbau und führt durch einen neuen Rechner. Zum Kopieren gibt es die Beispielseite [`vorlage/beispiel-rechner.html`](vorlage/beispiel-rechner.html).
